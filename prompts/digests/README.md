# Сводки по многим встречам в таблицу (Excel)

Одна папка = одна сводка. Вызов: `POST /assistant/digests {"name": "<папка>", "date_from": ..., "date_to": ...}`
(по умолчанию последние 7 дней). Результат: `data/output/digests/<id>_<имя>_<от>_<до>.xlsx`, те же строки в Postgres
(`digests`) и в ответе `GET /assistant/digests/{id}`.

    digest.yaml   колонки таблицы и выбор встреч
    system.md     роль и правила
    user.md       запрос к модели на ОДНУ встречу (те же метки, что в prompts/meetings/README.md)

Как строится таблица: на каждую встречу отдельный запрос к модели; она возвращает строки только с колонками из
`columns`, код приписывает служебные колонки из `meta_columns` (дата, файл...) и склеивает строки всех встреч.
Неделя встреч целиком модели не отправляется: не помещается в контекст маленькой модели.

digest.yaml:

    title: Дейлики за период
    kinds: [daily]                    # какие типы встреч брать (config/meeting_kinds.yaml); пусто = любые
    source: dialogue                  # dialogue — с разметкой говорящих (без неё берётся сырой текст), raw — сырой
    meta_columns: [date]              # заполняет код: date, file, kind, run_id, tags
    columns: [Сотрудник, Проект, Сделано, Планы, Блокеры]   # заполняет модель; это и заголовки в Excel
