# Промпты разбора картинок

Независимый разбор: фото + промпт -> текст модели. Со встречами не связан. Модель должна уметь vision (у `qwen3.5:4b` умеет).

    prompts/images/<имя>/system.md   роль и правила
    prompts/images/<имя>/user.md     запрос к картинке

Метки в `user.md`: `{file}` (имена файлов), `{count}` (сколько картинок), `{date}` (сегодня), `{tags}`.

Вызов: `POST /assistant/images/analyze {"files": ["доска.jpg"], "prompt_name": "<папка>"}` или свой текст без папки:
`{"files": [...], "prompt": "Что на фото?"}`. Файлы читаются на каждый запрос, перезапуск не нужен.

Советы для маленькой модели: чётко описывайте формат ответа, запрещайте домысливать, просите писать «нечитаемо» вместо догадок.
Плотные таблицы, рукописный и мелкий текст она читает хуже печатного: фотографируйте крупно и ровно.
